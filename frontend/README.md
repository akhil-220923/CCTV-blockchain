# Web Enchantments

Add effects to website without disturbing the existing UI
1.underline hover for nav bar items
2.countup for intrusion count
3.animated gradient with suitable colours for landing page
4.tilt card for first three  cards in 3 node ledger.
5.reveal from click for pages navigated from navbar in command center.
6.scroll and watch the page respond to landing page with suitable colours.
7.word by word effect for the text in landing page "Intelligence border video analytics".
